## IntelliJ 설치방법

Community(무료) 버전과 Ultimate(유료) 버전으로 나뉘어있는데 이번 편에서는 Community버전 설치


[다운로드 링크](https://www.jetbrains.com/ko-kr/idea/download/other.html)


## 유용한 단축 키
  (window)
  - Ctrl + B : 해당 함수가 정의된 위치로 바로 이동
  (mac)
  - command + shift + . : 파인더에서 보기
  - command + ; : 버전 바꾸기 설정 가능
  - option + enter : 컨텍스트 메뉴
  - command + l (?) : Show Context Menu(import 쉽게 한다.)
